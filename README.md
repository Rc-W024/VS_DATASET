mmWave Radar System-on-Chip (RSoC) is a transformative technology for wireless, privacy-preserving, continuous vital sensing and smart healthcare monitoring. This repository hosts two unique, high quality datasets collected using our **120 GHz FMCW RSoC**.

To support advanced techniques R&D and IoMT applications, the dataset comprises recordings from two distinct cohorts:
- [**Healthy**](https://github.com/Rc-W024/VS_DATASET/blob/main/HEALTHY.md)**:** 24 subjects, Resting + Apnea (2-min for each recording)

- [**Patients**](https://github.com/Rc-W024/VS_DATASET/blob/main/PATIENT.md)**:** 15 participants, clinical data capturing specific anomalies and disease markers (10-min for each recording)

> [!TIP]
> To make the results more persuasive and interpretable, it is highly recommended to calculate RR and HR by applying the same processing methods to both the radar and reference signals, such as inter-beat interval (IBI) based calculation or spectrum based estimation, rather than directly comparing algorithm-derived results to the rate values outputed by the reference monitor, which may introduce algorithmic bias.
> By using a "level playing field" approach ensures that any performance gaps are strictly due to the proposed algorithm itself and original signal quality, eliminating variables such as processing bias or algorithmic mismatch.
